# Savability

Project Overview

Savability is a webapp made for the Dezerv 2026 Children's Day Hackathon made by Arnav Namjoshi.

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
